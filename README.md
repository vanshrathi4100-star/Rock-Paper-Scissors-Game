🌟 About The Project

Rock Paper Scissors is a classic hand game recreated as a simple and interactive web application. Players can compete against the computer, make strategic choices, and track their scores in real time.

This project demonstrates the use of JavaScript logic, DOM manipulation, event handling, and dynamic UI updates.

✨ Features

* 🎯 Interactive gameplay
* 🤖 Random computer moves
* 🏆 Real-time score tracking
* 🎨 Attractive and simple user interface
* 🟢 Green color for winning
* 🔴 Red color for losing
* 🤝 Draw detection
* ⚡ Instant game results

🛠️ Tech Stack

Technology	Purpose
HTML5	Structure of the game
CSS3	Styling and layout
JavaScript	Game logic and interactivity

🎮 Gameplay

The player selects one of the three options:

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors

Rules

Player Choice	Beats
Rock 🪨	Scissors ✂️
Paper 📄	Rock 🪨
Scissors ✂️	Paper 📄

The computer randomly selects its move, and the winner is determined automatically.
